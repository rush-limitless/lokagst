\section{Présentation Générale}

ImmoGest est une application web de gestion locative développée pour \textbf{IMMOSTAR SCI}, société civile immobilière basée à Yaoundé, Nkolfoulou. Elle permet la gestion complète de 3 biens immobiliers totalisant 32 logements.

\begin{itemize}
  \item \textbf{Résidence La'ag Tchang} — 28 logements (RDC + 5 étages)
  \item \textbf{Santa Barbara} — 2 logements (RDC + Étage)
  \item \textbf{Villa Omnisports} — 1 villa
\end{itemize}

\subsection{Stack Technique}
\begin{itemize}
  \item Next.js 14 (App Router, Server Components, Server Actions)

\end{itemize}

\subsubsection{Logique de calcul}
Les paiements sont filtrés sur les 12 derniers mois pour les performances. Le cache est invalidé à chaque nouveau paiement ou modification de bail (revalidateTag).

\subsection{Situation Globale}

Vue synthétique de tous les locataires avec leur statut de paiement (à jour ou en retard).

\subsubsection{Logique de calcul du Total Dû}
Pour chaque bail actif, le système :
\begin{enumerate}
  \item Identifie les mois d'échéance selon la périodicité du bail
  \item Pour chaque échéance passée : vérifie si les paiements couvrent le montant attendu
  \item \textbf{Bail MENSUEL} : 1 échéance = loyer + charges par mois
  \item \textbf{Bail ANNUEL} : 1 échéance = (loyer + charges) $\times$ 12
  \item \textbf{Bail TRIMESTRIEL} : 1 échéance = (loyer + charges) $\times$ 3
\end{enumerate}

\textbf{Proratisation du Total Dû} (baux non-mensuels) :

Pour un bail ANNUEL/TRIMESTRIEL impayé, le total dû n'est \textbf{pas} l'échéance complète, mais le nombre de mois écoulés depuis l'échéance impayée multiplié par le mensuel :

\begin{equation}
\text{totalDû} = \text{totalMensuel} \times \min(\text{fréquence}, \text{mois écoulés depuis l'échéance})
\end{equation}

\textbf{Exemple TMCO} : Bail ANNUEL, échéance 01/01/2026 impayée. Au 03/06/2026 :
$$\text{totalDû} = 157\,500 \times \min(12, 6) = 157\,500 \times 6 = 945\,000 \text{ FCFA}$$

\subsection{Situation Locataire (détail)}

Page individuelle accessible depuis la Situation Globale. Affiche pour un locataire donné :

\subsubsection{Logique de calcul Attendu Multi-Baux}
Pour les locataires ayant eu plusieurs baux successifs sur le même appartement :

\begin{equation}
\text{attendu} = \sum_{\text{bail}} \text{montant\_bail} \times \text{nb\_échéances\_bail}
\end{equation}

\begin{itemize}
  \item \textbf{Baux MENSUELS} : $\text{attendu} = (\text{loyer} + \text{charges}) \times \frac{\text{jours}}{30}$
  \item \textbf{Baux ANNUELS/TRIMESTRIELS} : $\text{attendu} = (\text{loyer} + \text{charges}) \times \text{fréquence} \times \text{nb échéances passées}$
\end{itemize}

Le \textbf{total réglé} = somme de TOUS les paiements de TOUS les baux du locataire sur l'appartement.

Le \textbf{total encaissé} = total réglé + somme des cautions payées de tous les baux.

\subsubsection{Total Due Calculation Logic}

For each active lease, the system:
\begin{enumerate}
  \item Identifies payment due dates based on lease periodicity
  \item For each past due date: checks if payments cover the expected amount
  \item \textbf{Monthly lease}: 1 due = rent + charges per month
  \item \textbf{Annual lease}: 1 due = (rent + charges) $\times$ 12
  \item \textbf{Quarterly lease}: 1 due = (rent + charges) $\times$ 3
\end{enumerate}

\textbf{Prorated Total Due} (non-monthly leases):

For an unpaid annual/quarterly installment, the total due is \textbf{not} the full installment amount, but the number of months elapsed since the unpaid due date times the monthly amount:

\begin{equation}
\text{totalDue} = \text{monthlyTotal} \times \min(\text{frequency}, \text{months elapsed since due date})
\end{equation}

\textbf{Example TMCO}: Annual lease, installment due 01/01/2026 unpaid. As of 03/06/2026:
$$\text{totalDue} = 157{,}500 \times \min(12, 6) = 157{,}500 \times 6 = 945{,}000 \text{ FCFA}$$

\subsection{Tenant Detail (Situation)}

Individual page showing for a given tenant:

\subsubsection{Multi-Lease Expected Amount Formula}

For tenants with multiple successive leases on the same apartment:

\begin{equation}
\text{expected} = \sum_{\text{lease}} \text{lease\_amount} \times \text{nb\_installments}
\end{equation}

\begin{itemize}
  \item \textbf{Monthly leases}: $\text{expected} = (\text{rent} + \text{charges}) \times \frac{\text{days}}{30}$
  \item \textbf{Annual/Quarterly}: $\text{expected} = (\text{rent} + \text{charges}) \times \text{freq} \times \text{past installments count}$
\end{itemize}

\textbf{Total collected} = sum of ALL payments from ALL leases for that tenant on the apartment.

\textbf{Total received} = total collected + sum of all paid security deposits across all leases.
